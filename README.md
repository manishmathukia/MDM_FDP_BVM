# 🛒 Smart Shopping & Retail Intelligence Agent

An AI-powered **consumer-protective shopping assistant** built using **LangFlow, IBM watsonx.ai, and Granite-4.0-H-Small**.  
The system helps users make **intelligent, data-driven purchasing decisions** through product comparison, review analysis, and predictive insights.

---

## 🚀 Project Overview

This project is an **Agentic AI-based Smart Shopping Assistant** that acts as a retail analyst rather than a simple chatbot.  
It analyzes user requirements and provides structured insights such as:

- Product comparisons across platforms  
- Value-for-money scoring  
- Fake/biased review detection  
- Buy vs Wait predictions  
- Better alternative recommendations

## 🤖 Role of AI Agent

The Agentic AI system:
- Understands user preferences (budget, urgency, needs)  
- Analyzes product specifications and reviews  
- Detects fake or unreliable feedback patterns  
- Computes value-for-money score  
- Provides smart purchase recommendations

→ Product Analysis + Comparison
